# 邮箱验证码读取

注册、登录、注销等流程应先记录邮箱水位线，再触发 APP 发送验证码，最后只读取水位线之后到达的邮件。这样即使邮箱保留旧验证码，也不会误用。

```python
from studio.mailbox import VerificationMailbox

mailbox = VerificationMailbox(root)
checkpoint = mailbox.checkpoint()      # 必须在点击“发送验证码”前执行
# 点击 APP 的发送验证码按钮
answer = mailbox.wait_for_code(checkpoint, timeout=90)
code = answer['code']                  # answer['uid'] > checkpoint['uid']
```

实现使用 IMAP SSL 的 UID 作为请求前水位线，并在登录后发送 163 要求的 IMAP ID（VisionRay / DPVR QA）。`wait_for_code` 只遍历 UID 大于该水位线的邮件，并提取主题或正文中的 4 至 8 位验证码。

邮箱账号及授权码仅保存在 `configs/mail_private.json`，已列入 `.gitignore`，不会写入日志、证据目录或测试结果。

若服务器拒绝读取收件箱，框架会保留服务器返回的原因；必须先在邮箱服务端解除限制后再执行自动化，不会退回读取旧邮件。
