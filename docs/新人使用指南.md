# VisionRay 自动化：新人快速上手

## 1. 下载项目

把 `download_visionray.cmd` 放到准备存放项目的文件夹，双击运行。脚本会安装或检查 Git，并在当前文件夹下载 `VisionRay`；以后再次运行会更新已有项目。下载失败时查看窗口提示，完整日志在 `%TEMP%\download_visionray.log`。

## 2. 配置环境

进入 `VisionRay` 文件夹，双击 `setup_environment.cmd`，等窗口显示环境检查通过。脚本负责安装和检查 Python 依赖、Android SDK、Appium 等工具；安装失败时查看窗口中的“需要处理”和 `%TEMP%\setup_environment.log`。完成后关闭并重新打开工作台。

手机开启 USB 调试，连接电脑并在手机上允许调试授权。双击 `启动Windows测试工作台.cmd`，点击“刷新设备”确认手机已显示。

## 3. 执行与查看结果

在工作台选择 Excel 用例文件、手机、眼镜型号及蓝牙完整名称，填写 APP 三段数字版本号（例如 `1.2.49`），勾选模块后点“开始执行”。右侧会显示当前用例、通过/失败状态和关键日志。

执行结束后点“打开结果目录”。结果始终保存在 **项目文件夹的 `runs` 目录**，例如项目放在 `C:\Users\用户名\Desktop\VisionRay`，结果就在 `C:\Users\用户名\Desktop\VisionRay\runs`。

单型号运行：打开 `runs\本轮编号\`，例如 `runs\20261106_103000_ab12cd34\`。其中：

- `report.html`：结果概要、模块汇总和每条用例的原因；点击自动化编号可打开证据。
- `results.xlsx`：本轮回填结果的 Excel，原始用例文件不作为本轮结果查看。
- `evidence/自动化编号/`：该用例的截图、操作记录、日志等证据。

一次运行多个型号：先打开 `runs\batches\批次编号\report.html` 看总览；每个型号的完整报告与证据仍在 `runs\各自轮次编号\`，可从批次报告点击“打开报告”进入。

## 4. 出问题时发给开发者

请提供 **用例编号、自动化编号、测试手机与眼镜型号、APP 版本**，并附上本轮的 `report.html` 和对应的 `evidence/自动化编号/` 文件夹。说明实际看到的现象、期望结果，以及是否能复现。

若测试在用例开始前就报错，再附上弹窗完整文字和相关日志：下载问题提供 `%TEMP%\download_visionray.log`；环境安装问题提供 `%TEMP%\setup_environment.log`；工作台启动问题提供 `runs/workbench-errors.log`；Appium 会话问题提供 `runs/appium-service.log`。
