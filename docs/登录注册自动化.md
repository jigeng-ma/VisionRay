## 账号和恢复

脚本只操作 `test_zsb@163.com`，初始及恢复密码为用户提供的 `1234qwer`。发现其他账号会阻塞。验证码复用 `studio/mailbox.py`，先记录 UID，再请求和读取新邮件；不输出邮箱授权码或收到的验证码。

每条用例先检查账号和页面前置条件。要求已注册时，发现未注册会先完成注册；发现密码不符会通过邮箱恢复。要求未注册时，仅当账号存在才注销，已注销时直接准备目标页面。准备失败标记为阻塞，不继续执行不满足条件的业务步骤。发现其他账号仍会停止。

注册页检查可以保留未注册状态，下一条独立判断并准备，不再每条都强制重新注册。删除的服务器数据不会恢复。改密用例仍在结束时恢复原密码并验证登录，恢复失败以 teardown ERROR 报告。即使上一条的恢复中断，下一条也会从实际账号状态重新准备。完整顺序执行的最后一条 AUTH_095 会准备并保留有效登录。

每条用例可单独执行；页面动作先确认目标页面，进入输入页后收起键盘，避免遮挡协议等底部控件。注册、找回及注销发送验证码后，先确认进入验证码页。明确的短时限流等待65秒再试，最多3次；每日上限或无法确认发送结果记录为阻塞。重发后收信超时也记录阻塞及可取得的服务端原因。不要并发运行同一手机或同一测试邮箱。
